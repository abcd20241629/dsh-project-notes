# 项目笔记 · dsh-project-notes

给 DSH 加一块**便签墙**：把在 dsh 里冒出来的设想、提示词、半成品，一张张摊在无限画布上，连起来、组起来、随时一键复制回对话。

![icon](icon.svg)

## 它解决什么

- 提示词散落在聊天记录里，翻不到、复用难。
- 一个想法想出到第三层，忘了第一层是怎么来的。
- 想给 agent 一段干净的上下文，却只能手抄。

项目笔记把每一段想法变成一张卡片：写、标、连、组、复制。

## 功能

**画布**
- 无限画布：滚轮缩放（以鼠标为中心）、按住鼠标中键拖动平移、`Ctrl+0` 适应内容。
- 双击空白处新建卡片；卡片自由拖动。
- 空白处左键拖框可以框选（和 ComfyUI 一样），选中多张后再拖就整块移动。

**卡片**
- 圆角便签，8 种颜色：选中卡片后右键，点色块即换。
- **单击正文直接进入编辑**；点卡片标题栏则退出编辑并保持选中，这样 `Delete` 删卡片、方向键都不会被编辑区吞掉。选中文字会浮出工具条：加粗、6 色荧光笔、橡皮擦。
- 字号跟随 DSH 界面字号，卡片宽度可拖右下角调整；高度由内容撑开，**永不裁字**，写多少长多少。
- 每张卡片一个复制按钮，复制的是纯文本（荧光笔和加粗不带走，粘进对话框干净）。
- 右键「复制并返回对话」= 复制 + 自动切回对话面板，`Ctrl+V` 直接发。
- 可挂附件（任意格式）：文件会复制一份进项目目录，原文件删了也不失效。**点附件名在插件里直接预览**：文本/Markdown/代码显示成可滚动的白底阅读窗（可一键复制全文），图片显示大图；其他类型交给系统程序。
- 预览窗以外的场景用右键：「用系统程序打开」。
- 图片附件直接显示缩略图，点开看原图。
- 附件右上角悬停出 `×` 删除；右键附件可「复制文件 / 复制文件路径 / 打开 / 删除」。「复制文件」放进的是系统剪贴板的真实文件，可以直接在资源管理器里 `Ctrl+V`。
- 收藏（★）用于把重要的卡挑出来。

**连线**
- 从卡片四边的小圆点拖出来，落到另一张卡上即连线。
- 荧光蓝直线，端点自动吸附到最近的那条边。
- 线中点自带一个单行文本框写标注，**无论线怎么倾斜，标注永远是水平的**，字号与界面一致。
- 选中卡片时，连在它身上的线会变白并发光，一眼看出关联。
- **点线（或点线上那个标注框）可以单独选中这条线**，选中的线同样变白发光；右键出菜单：`⇥ 合并这两张卡` / `✕ 删除这条连线`。
- **合并**会把连线两端的卡片并成一张：左右连时左的在上、右的在下，上下连时上面的在上；两段文字之间空一行。另一张卡被并走，它原来的连线一并断掉。
- 双击线可删除。

**剪刀（空格）**
- 按住 `空格` 进入剪刀模式（鼠标变十字），松开退出。
- 划过连线 → 当场切断。
- 在一张卡片上画一条线、**起点和终点都落在同一张卡的边框上** → 卡片沿这条线切成上下两张，文字按切点分开；原卡和新卡都留在原来的组里。
- 切割轨迹是红色虚线，松手即消失。

**卡片组**
- 框选或 `Ctrl` / `Shift` 点选多张卡 → `Ctrl+G` 建组（也可以在右键菜单里建组）。
- 组的范围是**固定**的：建组时按当时的位置定框，之后挪卡片不会把框撑大；拖右下角可以手动改大小。
- 拖标题即整组平移；把卡片拖进组框旁边会自动归组。
- 标题必填，白底蓝字加粗，字号是卡片字号的 **1.3 倍**，固定在组框左上角。
- 双击标题改名，右键标题删除组（卡片保留）。

**项目**
- 侧边栏「项目笔记」入口 → 项目列表（名称 / 卡片数 / 更新时间），新建、重命名、复制、删除（进 `_trash/` 不真删）、导入 JSON。
- 一个画布 = 一个项目，全部卡片、连线、分组、视口位置一起保存。
- **会自动记住上次打开的项目**：切到别的面板再切回来，直接回到那张画布，不用重新点。
- **悬浮球，与会话同屏**：插件一加载，右下角就浮着一颗球（不用从侧边栏进）。点球展开 440px 宽的窄画布（左边继续聊天），拖左侧边缘改宽度，右上角「✕」收回成球，「⤢ 展开」回全屏。画布顶栏的「⭘ 收成悬浮球」也能把全屏收成球。球可以拖到任意位置，位置和状态刷新后都保留；右键球可以隐藏（会记住），从侧边栏进一次面板即恢复。
- 自动保存（输入停止 500ms 落盘），不需要按保存。
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`，50 步）。
- 导出 JSON（可再导入）/ 导出 Markdown（喂给 AI 当上下文最顺手）。

## 存储位置

全局共享，不绑工作区：

```
%DSH_HOME%/project-notes/          # 默认 D:\dsh\.dsh\project-notes
  <project-id>/
    project.json                   # 卡片 / 连线 / 分组 / 视口
    attachments/<stored-name>      # 附件副本
    <项目名>-<时间>.json / .md      # 导出的文件
  _trash/<project-id>-<时间>/       # 删除的项目
```

## 安装

开发态（本机热注入）：

```bash
dev_inject_plugin  dir = <本包目录>
```

正式态：在 DSH 里用 `plugin_manager install_bundle`，target 指向本包目录。

## 结构

```
dsh-project-notes/
  package.json        # dsh.client = web 平台，exports ./client
  cordis.patch.yml    # loader 入口（id: project-notes）
  icon.svg
  locale/{zh,en}.json
  lib/
    index.js          # Host：node:fs 存储 + /api/dsh-project-notes/* 同源路由
    client.js         # Client：React 面板（无外部依赖，React 由模块表提供）
```

Host 路由：`list / create / load / save / rename / duplicate / remove / import / export / upload / open / reveal / attachment / attach-path / remove-attachment`。
所有响应统一 `{ ok, value }` 或 `{ ok:false, code, message }`；只接受同源请求。

## 设计取舍

- **高度由内容决定，只让用户拖宽度**：用户永远不需要为「文字被裁掉」操心，最小尺寸天然成立。
- **荧光笔浮条而不是右键菜单**：写东西时手不离开选区，右键只留给卡片级操作。
- **组框固定大小**（对着 ComfyUI 改）：建组时按当时位置定框，之后挪卡片不撑框，拖右下角手动改——避免「组越用越大、最后套住半个画布」。
- **单击即编辑，标题栏退出**：点正文立刻能打字；要删卡片就点一下标题栏（退出编辑、保持选中），再按 `Delete`。
- **卡片固定浅色便签底**：不跟深色主题走，保证自定义颜色的可读性；面板本身是玻璃底，跟壁纸协调。
- **复制是纯文本**：粘进输入框不给对方塞一堆 HTML。

## 已知限制

- DSH Client 没有写输入框的 API，「插入输入框」是复制后切回对话，需要手动 `Ctrl+V`。
- 主面板不绑定会话，因此没有「按当前会话过滤」之类的上下文。
- 附件上传上限 50 MB。
